# CRP-Content

**Part of the CRP (CEO Review Protocol) framework. Use this when reviewing and restructuring content for wider audience appeal. For strategic decisions, use `crp:decision` instead.**

## Overview

CRP-Content helps creators shift from "author perspective" to "content team perspective" — systematically reviewing and restructuring scripts, articles, and video drafts through multiple professional lenses.

**Core principle:** Great content is not produced by a single author expressing themselves. It emerges when multiple professional roles examine the material together.

CRP-Content does not just polish text. It functions like a content team:
- Judges whether the material is worth spreading
- Finds public conversation hooks
- Optimizes narrative structure
- Elevates emotional value
- Eliminates low-value filler and ensures every sentence earns its place
- Preserves the author's unique voice
- Produces a version with higher propagation probability

## The Eight Roles

### 1. Hook Analyst

Analyzes whether the first thirty seconds grab an unfamiliar audience.

Focuses on:
- Does the opening contain strong conflict?
- Is there a counter-intuitive point?
- Would an ordinary user find it interesting?
- Is it just the author talking to themselves?
- Does it have headline potential for distribution?

Outputs:
- Current hook problems
- Optimization directions
- Recommended opening approach

### 2. Audience Psychologist

Reads from an ordinary viewer's perspective, not the author's.

Judges:
- Why would the viewer keep watching?
- Why would the viewer like/share?
- Why would the viewer comment?
- Which parts only interest industry insiders?
- How to lower the comprehension barrier?

Key focus: avoid content that only serves a vertical niche.

### 3. Story Editor

Optimizes the narrative structure of the content.

Checks:
- Is there a story starting point?
- Does conflict exist?
- Is there a turning point?
- Is there cognitive change?
- Is there emotional release?

Optimization direction: do not simply stack opinions.

Good structure:
```
Experience / Event
→ Conflict
→ Reflection
→ Methodology
→ Insight
```

### 4. Trend Observer

Judges whether the content connects to broader public conversations.

Analyzes:
- Is this just a personal experience?
- Can it reflect a larger shift of the times?
- Is there space for public discussion?

Example — instead of:
"I used AI to build a website"
Find the larger angle:
"Are ordinary people gaining abilities that only professionals had before?"

### 5. Retention Auditor

Analyzes churn risk during the viewing process.

Core question: **"Will the user leave here?"**

Checks:
- Which paragraphs might make the user leave?
- Is information density reasonable?
- Is there repetitive expression?
- Is a case study, conflict, or humor needed?
- Reading/viewing fatigue points
- Rhythm disruptions

### 6. Value Density Editor

Ensures every sentence, paragraph, and visual frame carries its weight.

Core principle:

> **Don't just make every sentence correct. Make every sentence worth reading.**

Core question: **"Why does this sentence deserve the user's time?"**

Checks:
- Does each sentence deliver new information, cognition, emotion, narrative, expectation, or relationship value?
- Are there empty transitions, hollow openings, redundant restatements, or disclaimers that add no value?
- Could three sentences be compressed into one without losing meaning?
- Does each paragraph produce something new, or just restate the same point?
- For video: does each frame serve a function — information, evidence, contrast, story progression, emotion, anticipation, understanding, or visual satisfaction?

Value categories — every sentence should serve at least one:

1. **Informational** — new facts, data, cases, details
2. **Cognitive** — new understanding, judgment, or perspective shift
3. **Emotional** — resonance, surprise, humor, tension, contrast
4. **Narrative** — advances the story, event, or character
5. **Anticipatory** — makes the user want to see what happens next
6. **Relational** — helps the user understand the author's personality, experience, or choices

The "delete test" — for each suspicious sentence:

> **If this sentence is removed, what does the user lose?**

If there is no information loss, no cognitive loss, no emotional loss, no story progression loss, no anticipation loss, and no increase in comprehension cost → **delete it.**

Identify and eliminate these patterns of pseudo-value content:
- **Hollow openings** ("Today I want to talk about a very important problem") — if the real value can start directly, start directly.
- **Hollow transitions** ("This is actually a very thought-provoking problem") — if the real insight follows, go straight to the insight.
- **Disclaimer filler** ("Of course, this is just my personal opinion") — only keep when the context genuinely requires qualification.
- **Redundant restatements** — three sentences saying the same thing should be compressed into one higher-density expression.
- **Hollow conclusions** ("So we can see this is very meaningful") — if no new cognition is added, delete.
- **Excessive buildup** — reduce "preparing to say something" and increase "actually saying something."

> **The goal is not to say more. The goal is to make every unit of content matter.**

#### Value Density Score

After completing the analysis, assign a **Value Density Score: X/100** based on:

| Range | Meaning |
|-------|---------|
| 90–100 | Almost no filler. Every sentence serves a clear purpose. |
| 75–89 | Overall tight. Minor expressions could be compressed. |
| 60–74 | Noticeable redundancy, buildup, and hollow expressions present. |
| 40–59 | Low value density. Large portions do not effectively advance the content. |
| <40 | Severe filler problem. Content structure needs rethinking. |

**Score is not based on length.** Short content can have low density. Long content can have high density. The criterion is: **how much effective value does the user gain per unit of reading time?**

#### Value Density Editor vs Retention Auditor — Clear Boundary

| | Retention Auditor | Value Density Editor |
|---|---|---|
| **Core question** | "Will the user leave here?" | "Why is this sentence worth the user's time?" |
| **Scope** | Churn risk, rhythm, fatigue, boredom | Per-sentence value, information compression, filler |
| **Output** | Where the user might leave | What should be deleted, compressed, or rewritten |
| **Relationship** | Identifies WHERE | Explains WHY that part doesn't deserve to exist |

These two roles must not be merged. Retention Auditor spots the drop-off point. Value Density Editor explains why the content at that point isn't worth the user's time in the first place.

### 7. Voice Guardian

Protects the author's personal expression style.

Ensures the revision does NOT:
- Turn into AI-generated essay style
- Lose personal humor
- Become overly commercialized
- Delete authentic experiences

Must preserve:
- The author's oral expression habits
- Self-deprecating humor
- Emotional variation
- Authenticity in the entrepreneurial journey

### 8. Chief Editor

The final integration role. This is NOT a simple summary of the other roles' opinions.

Responsibilities:
1. Aggregate issues found by all roles
2. Judge which suggestions are worth adopting
3. **Execute Value Density Editor's recommendations — delete, compress, restructure before polishing**
4. Redesign the article structure
5. Output a complete optimized version

New rewrite principle — **Delete before polishing:**
- If a sentence has no value → **delete it**
- If three sentences express one point → **compress them**
- If a paragraph adds no new cognition → **restructure it**
- If a claim lacks evidence → **add a case, data, or real experience** — do not just add adjectives

Principle: do NOT output a "list of suggestions." The final output must be a publish-ready new version.

## Workflow

```
Idea Evaluation
↓
Public Interest Check
↓
Hook Review
↓
Story Structure
↓
Emotional Resonance
↓
Differentiation
↓
Value Density Audit
↓
Retention Prediction
↓
Voice Protection
↓
Chief Editor Rewrite
↓
Final Content
```

**Value Density Audit must be completed before Chief Editor Rewrite.** The Chief Editor must incorporate Value Density Editor's judgments — not simply trim words in the final stage.


### Part 2: Chief Editor Rewrite

A complete, publish-ready rewrite of the content.

### Part 3: Why This Version Is Better

Brief explanation of:
- What propagation points were strengthened
- What problems were solved
- Why this version is better suited for mass distribution

## Important Rules

1. Do NOT sacrifice authenticity for distribution optimization.
2. Do NOT turn the author into a marketing account.
3. Priority chain: Personal experience → Public issue → Universal emotion.
4. Ordinary people's resonance takes priority over industry expert approval.
5. The goal is not to make the text more beautiful — it's to make more strangers willing to stop and engage.
6. Always preserve the author's voice.
7. **Every sentence must earn its place.**
8. **Do not confuse completeness with value.**
9. **The goal is not to say more. The goal is to make every unit of content matter.**
